# Weather Intelligence Application

An AI-generated, interactive weather intelligence web application built with React, TypeScript, and Vite, utilizing the Open-Meteo API for real-time forecast data.

## 🚀 Live Demo
- **Live Deployment:** [https://weather-intelligence-app.nikhil-chandra.workers.dev](https://weather-intelligence-app.nikhil-chandra.workers.dev)
- **GitHub Repository:** [https://github.com/nikhilchandra-oss/weather-intelligence-app](https://github.com/nikhilchandra-oss/weather-intelligence-app)

## ✨ Features
- **City Search & Geocoding:** Search for weather data across global locations using Open-Meteo Geocoding API.
- **Current Weather & Forecasts:** Displays real-time temperature, weather conditions, wind speed, and short-term forecasts.
- **Error Handling:** Gracefully handles non-existent cities or invalid queries with user-friendly notices.
